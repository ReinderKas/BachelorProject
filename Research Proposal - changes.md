Explainable AI

We know a solver can generate 'satisfiable' 'unsatisfiable' or 'unknown' answers. A user would like to know why a CSP Feature model is unsatisfiable. This would ideally be the minimal set of changes to make the model satisfiable again. I'd like to investigate an intuitive way to generate and visualize this for a user.
